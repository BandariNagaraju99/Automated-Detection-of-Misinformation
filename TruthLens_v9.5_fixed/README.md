# 🔬 TruthLens — AI Fake News Detector

Real-time fake news detection using **ANN + RAG** architecture.  
Combines writing-pattern analysis (ANN) with live news evidence (FAISS + RSS).

---

## Setup

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. (Optional) Train ANN on WELFake
```bash
# Download WELFake dataset from Kaggle:
# https://www.kaggle.com/datasets/saurabhshahane/fake-news-classification
# Place WELFake_Dataset.csv in the project folder, then:

python train.py
```
This produces `ann.pth` (~1 MB).  
If you skip this step, the system still works using only the RAG pipeline.

### 3. Start the backend
```bash
python app.py
# → http://localhost:5010
```

On startup the system will:
1. Load the ANN model
2. Fetch ~1 000+ live articles from BBC, Reuters, NDTV, etc.
3. Build the FAISS index
4. Begin auto-refreshing every 10 minutes

## Decision Logic

```
final_real = 0.60 × rag_similarity + 0.40 × (1 − ann_fake_prob)
```

| real_score | Verdict      |
|-----------|--------------|
| ≥ 0.72    | REAL         |
| ≥ 0.58    | LIKELY REAL  |
| ≥ 0.44    | UNCERTAIN    |
| ≥ 0.28    | LIKELY FAKE  |
| < 0.28    | FAKE         |

## Notes

- The ANN alone is **not the sole decision maker** — RAG evidence always co-influences the result.
- Claims with no similar news → similarity defaults to 0.5 (neutral), preventing false "FAKE" verdicts.
- The FAISS index auto-refreshes every 10 minutes in a background thread.
- For GPU acceleration: swap `faiss-cpu` → `faiss-gpu` in requirements.txt.
